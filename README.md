# ReadEveryday 浏览器体验版

此仓库为自动生成的发布产物。页面、文章、词卡均来自维护中的本机项目，不在这里单独修改。

内容版本：`27c8dac20f66bded`；28 篇、534 个学习单元。

直接打开 GitHub Pages 地址即可使用，无需 Python、VBS 或账号。学习进度、历史和收藏只存在当前浏览器，可在设置中按文章导入导出。此版本未接云同步，未提供完整离线缓存。

维护者在原项目双击“发布浏览器版.cmd”，即可重新构建并推送。回滚通过 git revert 撤销指定发布提交，再推送 main；浏览器学习记录不会上传或被发布覆盖，回滚内容时应保留已有文章和句子身份。
