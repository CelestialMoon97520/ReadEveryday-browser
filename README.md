# ReadEveryday 浏览器体验版

此仓库为自动生成的发布产物。页面、文章、词卡均来自维护中的本机项目，不在这里单独修改。

内容版本：`6f6e233698672c5d`；28 篇、534 个学习单元。

直接打开 GitHub Pages 地址即可使用，无需 Python 或 VBS。访客记录保存在当前浏览器；邀请账号登录后，进度、历史和词本保存到 Supabase，各账号通过 RLS 隔离。访客记录不自动上传；可在设置中按文章导出、登录后自行导入。此版本未提供完整离线缓存。

维护者在 ReadEveryDay_Process 双击“同步网页版.cmd”重新生成；“发布浏览器版.cmd”另行构建并推送。共享页面源码在 ReadEveryDay，浏览器适配源码在 ReadEveryDay_Process/browser。回滚通过 git revert 撤销指定发布提交，再推送 main；回滚网页不删除云端个人数据，回滚内容时应保留已有文章和句子身份。
