# ReadEveryday 浏览器体验版

此仓库为自动生成的发布产物。页面、文章、词卡均来自维护中的本机项目，不在这里单独修改。

内容版本：`680364bfbfd547b6`；28 篇、534 个学习单元。

直接打开 GitHub Pages 地址即可使用，无需 Python 或 VBS。访客记录保存在当前浏览器；在独立登录入口用账号、密码登录；新注册另需管理员提供的一次性激活码。账号与密码区分大小写，密码至少 6 位。登录后进度、历史和词本保存到 Supabase，各账号通过 RLS 隔离，每账号个人进度总量上限 15 MiB，单篇不另设容量额度。超额保存会拒绝本次写入并保留未同步副本，可在设置中导出备份。找回密码暂未开放；访客记录不自动上传；可在设置中按文章导出、登录后自行导入。换篇在页面内完成；文章和词卡按发布版本缓存并有限预加载。已有账号副本先显示再核对云端，未同步时仍有提示。首次访问、未缓存内容和云同步需要联网，浏览器可能清理缓存；尚未提供完整离线启动。

维护者在 ReadEveryDay_Process 双击“同步网页版.cmd”重新生成；“发布浏览器版.cmd”另行构建并推送。共享页面源码在 ReadEveryDay，浏览器适配源码在 ReadEveryDay_Process/browser。回滚通过 git revert 撤销指定发布提交，再推送 main；回滚网页不删除云端个人数据，回滚内容时应保留已有文章和句子身份。
